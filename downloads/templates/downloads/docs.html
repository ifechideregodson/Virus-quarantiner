Using ShieldScan

ShieldScan needs Python 3.8 or newer and nothing else. Run python --version to check; on macOS and Linux the command may be python3.

Commands

python shieldscan.py scan PATH [--quarantine] [--include-suspicious]
                               [--report report.json] [--html report.html]
                               [--rules rules.txt] [--exclude NAME ...]
python shieldscan.py watch PATH [--interval 5] [--quarantine]
python shieldscan.py list-quarantine
python shieldscan.py restore ID

--quarantine moves malicious files to ~/.shieldscan/quarantine. Add --include-suspicious to move suspicious files too. Nothing is ever deleted, and restore puts a file back. watch only checks files that arrive after it starts, so run scan on the folder once first.

How it decides

Each file gets a score. 3 to 7 is Suspicious, 8 and above is Malicious. A script needs a combined script score of at least 3 before it is reported, because one weak signal is common in harmless scripts.

Plain limits

It does

  • Scan files, folders and ZIP archives on demand
  • Watch a folder and check new files within seconds
  • Explain every flag in plain words
  • Keep quarantined files restorable

It does not

  • Protect you at the system level the way Defender does
  • Open RAR, 7z or password-protected archives, or detect brand-new malware families
  • Update itself or check the cloud
  • Replace Microsoft Defender, Malwarebytes or another full product
