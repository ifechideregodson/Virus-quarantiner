ShieldScan

A small antivirus scanner you download, read and run on your own machine. It checks files and ZIP archives against known-bad hashes, spots disguised and packed programs and suspicious scripts, watches a folder for new downloads, and moves what it finds into quarantine. It never deletes anything and never connects to the internet.

What it checks

Four layers, all readable

Signature check

Every file is hashed with SHA-256 and compared with the signature list. The EICAR test file is built in.

Disguise and packing

Catches a program renamed to .jpg or .pdf, names like invoice.pdf.exe, and executables that look packed or encrypted.

Script check

Scores PowerShell, batch, VBScript, JavaScript and shell files for hidden windows, encoded commands and download-and-run tricks.

Archives and watch mode

Looks inside ZIP files, skips zip bombs, and checks new files in a folder every few seconds.

Get running

Download, unzip, scan

  1. Download the ZIP and unzip it. You need Python 3.8 or newer. Nothing else to install.

  2. Scan a folder.

    python shieldscan.py scan ~/Downloads --html report.html

  3. Quarantine what it finds by adding --quarantine. Undo with restore. See the docs for every command.
